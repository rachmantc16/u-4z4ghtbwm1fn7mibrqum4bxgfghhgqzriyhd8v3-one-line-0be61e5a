A tiny program that writes one self-contained joke — a single line of at most 140 characters, with no trailing newline — to `/output/entry.txt` (or to `MAKEFUN_OUTPUT_DIR/entry.txt` when that environment variable is set). The line riffs on therapy billed by the hour: the narrator speedruns their trauma and spends the leftover minutes on small talk.

## Run it

```sh
node main.ts
```
